# 我的 Codex Skills

## 每日 Python 编程教练

`daily-python-coach` 用于连续学习 Python：根据学习进度安排练习、检查实际保存的代码，并记录已经确认的学习结果。

主要约定：

- 使用简体中文，先说明概念的用途，再给小例子。
- 一课约 30 分钟，以动手练习为主。
- 训练文件分为例子、题目与作答区、参考答案三个区域。
- 批改时保留学习者的代码，根据实际提交更新进度。
- 学习主线是逐步制作个人资料检索小助手。

## 在自己的项目中使用

这是一个依赖项目进度文件的 skill。将 `skills/daily-python-coach` 整个文件夹复制到学习项目的 `.agents/skills/` 目录下，形成以下结构：

```text
你的学习项目/
├── .agents/
│   └── skills/
│       └── daily-python-coach/
│           ├── SKILL.md
│           └── agents/
│               └── openai.yaml
└── 学习进度.md
```

在项目根目录创建 `学习进度.md`。新学习项目可以复制以下空白模板，并填写自己的情况：

```markdown
# 学习进度

## 学习目标
- 用 Python 逐步制作个人资料检索小助手。

## 当前水平
- 待根据首次交流和实际作答确认。

## 当前任务
- 尚未安排。

## 练习文件位置
- 待创建第一课时确定。

## 已确认内容
- 暂无。

## 卡点与下一步
- 先确认已有基础、学习目标和本次可用时间。
```

用 Codex 打开这个学习项目，在新聊天中指定 `daily-python-coach`，例如：

> 请使用 daily-python-coach。先读学习进度.md，根据我的水平安排一节 Python 练习。

之后可以说“继续学习”“检查我的代码”或“回顾进度”。
